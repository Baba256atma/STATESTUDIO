# Director Contract

Identity: `DIR:1/SemanticPresentationDirectorStageIntentFoundation`, version `1.0.0`.

The Director consumes resolved owner, presentation request class, references, canonical collection members/scope, relationship identity, and current Stage state. It deterministically emits desired presentation, satisfaction/mutation flags, reason, authority, and a permanent `businessMutationAllowed: false` guard. It receives no raw utterance.
