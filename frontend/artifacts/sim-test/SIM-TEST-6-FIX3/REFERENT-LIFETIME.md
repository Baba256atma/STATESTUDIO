# Referent lifetime (production)

CURRENT: remains the active conversation/executive subject until a legitimate new target resolves.

HISTORICAL: available for known named return (Delivery, Capacity). Not used as a silent stand-in for an unknown name.

EXPLICIT RETURN (known): 6.2 previous-referent selects the matching historical/catalog subject; 6.3 proceeds (including after superseding unrelated pending).

DEICTIC: follows current subject (FIX2 locative problem-here preserved).

NAMED TARGET (unknown): 6.2 UNRESOLVED + empty candidates → 6.3 MISSING_SUBJECT clarification. After FIX3 this still happens when the unknown return itself superseded a prior pending clarification.

LIFECYCLE TARGET: Decision/Execution/scenario queries still independently supersede empty pending without being forced through Supplier clarification.

UNKNOWN TARGET: Schedule, Resource, Supplier remain noncanonical; no fabricated objects.
