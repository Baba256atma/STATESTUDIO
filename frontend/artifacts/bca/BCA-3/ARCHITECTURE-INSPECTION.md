# BCA:3 architecture inspection

## Stop condition

Known BCA:2 concepts plus a BCA:1 context yield qualified, directed, scoped, non-causal relationship intelligence; general knowledge is distinct from current reality; source isolation and conflict provenance are preserved; no store, Advisor, Theatre, Object graph, or causal engine is added.

## Existing relationship authorities inspected (not reused as BCA truth)

| Authority | What it owns | Why BCA does not absorb it |
| --- | --- | --- |
| BCA:1 `contextualRelationships` | Concept → context-family membership | Context membership, not concept-to-concept structure |
| BCA:2 `safeAssociations` | Definitional names on one concept | Does not require the target to be present or carry direction/scope |
| DS:4 `relationship-intelligence` | Runtime object relationship profiles (strength/dependency numbers) | Executive object graph intelligence, not Business/Project concept structure |
| CORE-INT:3 / EI causal constraint | Evidence-bounded recorded causal/constraint interpretation | BCA must not mint CAUSES |
| ESI / DATA_OBJECT | Source → object support | Provenance of data, not concept pairs |
| ops dependency registries | Execution/schedule/task dependencies | Process/runtime dependency, not general concept knowledge |
| Director / Stage / DTH | Presentation edges | Must not auto-draw lines |

BCA:3 is a **read-only interpretation projection**. It reuses BCA:1 confidence, confirmation, evidence/source-ref shapes, and BCA:2 canonical names. Pair knowledge lives in a small BCA:3 registry because no existing authority answers “what structural relation may exist between these management concepts?”

## Intelligence chain

```text
DATA-ADV meaning → BCA:1 context → BCA:2 concept kind → BCA:3 safe relations
→ (not in this phase) BCA:4 process participation → Advisor / Theatre
```

## Manager confirmation

Consumed as `managerConfirmedRelationships` on the resolver input. Confirmation writes remain existing DATA-ADV / conversation authorities. Architecture gap: there is no BCA-owned writer, by design.

## Non-goals respected

No ontology engine, graph database, RAG, Advisor copy, Stage/DTH mutation, Object/Goal/Problem creation, or BCA:4 process model.
