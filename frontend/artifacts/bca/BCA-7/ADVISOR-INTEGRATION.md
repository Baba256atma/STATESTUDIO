# BCA:7 Advisor integration

Existing Advisor remains conversational authority. BCA:7 supplies `advisorContext`:

- role family and emphasis meanings
- decision-context areas
- process areas
- qualified non-causal relationship lines
- manager-facing explanation (jargon-free)
- clarification intent only when BCA:6 requires it

Same evidence + different role → different explanation, identical fingerprint.

BCA does not recommend, rank importance, or invent numbers.

Unknown role still explains Business/Project context. Ambiguous role asks only when BCA:6 says the task needs it.
