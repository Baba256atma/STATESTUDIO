# NPA-T OVS:AUDIT — Ownership Boundary

OVS is a visual/presentation system. It is not an intelligence authority.

```
Canonical Objects/Data
  → NMI / VAI / existing intelligence
    → DIR:1
      → DTH / DTH-EXP
        → OVS visual representation
          → Stage
```

## Owns

How certified scene content looks: object language, state appearance, relationship presentation, and 2D vs 2.5D/isometric vs simple-3D representation choice.

## Does not own

Director, Theatre, Stage, Object catalog, relationship engine, Data Reality, NMI, VAI, business state, chart intelligence, Manager workflow, SCENE-ORG regions, camera orbit, or Nexo family invention.

## Renderer

Extend `NexoraStageCanvas` / `ExecutiveObjectGeometryRenderer`. Do not add a second Canvas, CSS-3D object world, or chart library.
