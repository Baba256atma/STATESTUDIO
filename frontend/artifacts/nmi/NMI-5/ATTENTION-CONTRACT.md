# NPA-T NMI:5 — Attention contract

`NmiAttentionItem` is a read projection:

canonical reference, item type, title, STAGE-PROD:1 source, Queue category/object IDs, management context, related Goal, related roadmap, reasons, provenance, unresolved flag, navigation target.

`priority` is always UNKNOWN. `numericPriority` is always null.
