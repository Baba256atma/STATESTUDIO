# NPA-T NMI:1 — Ownership boundary

## NMI owns

- unified management-model contracts (`UnifiedManagementModel`)
- management relationship vocabulary
- management-path / read-model composition
- management-context projection contracts (context kind reused from BCA)
- references between existing canonical authorities
- provenance of how the management map was composed

## NMI does not own

- raw-data ingestion
- Gate API
- Data Reality
- semantic confirmation
- Object creation/mutation
- Goal mutation
- Stage mutation
- Advisor conversation
- causal truth
- scenario creation
- Decision approval
- Execution start/update
- Outcome observation
- durable Learning
- simulation ground truth
- Queue / Attention UI

NMI is an understanding/composition layer. Existing canonical writers remain authoritative.
