# NPA-T NMI:2 — Section model

Sections are management groupings, not a forced workflow.

| Section | Canonical node kinds |
| --- | --- |
| CONTEXT | BUSINESS_PROJECT, MANAGER_ROLE |
| GOALS | GOAL |
| OPERATIONS | PROCESS |
| KPI_DATA | KPI, DATA_EVIDENCE |
| PROBLEMS | PROBLEM |
| RISKS | RISK |
| VARIABLES | VARIABLE |
| SCENARIOS | SCENARIO |
| DECISIONS | DECISION |
| EXECUTIONS | EXECUTION |
| OUTCOMES | OUTCOME |
| LEARNING | LEARNING |

Empty sections remain empty (`[none]` in the manager-readable projection). Problems and Risks stay separate. Variables remain analytical references.
