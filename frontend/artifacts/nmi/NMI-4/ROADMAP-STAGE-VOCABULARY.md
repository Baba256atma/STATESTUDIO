# NPA-T NMI:4 — Roadmap stage vocabulary

CONTEXT, GOAL, OPERATION, KPI_DATA, ISSUE, ANALYSIS, SCENARIO, COMPARISON, DECISION, EXECUTION, OUTCOME, LEARNING_REASSESSMENT.

ISSUE may hold Problem and/or Risk. ANALYSIS holds VAI variables and analytical relationships.

Stages are omitted in content when empty; status still records MISSING, NOT_REACHED, or NOT_APPLICABLE. Not every roadmap contains every stage as PRESENT.
