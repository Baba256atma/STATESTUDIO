# NPA-T NMI:4 — Current-position logic

Position is the furthest PRESENT / PARTIAL / UNRESOLVED stage, with descriptive pairing:

- ISSUE + ANALYSIS when analysis is present or partial and no Scenario yet
- SCENARIO + COMPARISON when canonical comparison exists
- DECISION / EXECUTION / OUTCOME when those stages are the furthest reached

`descriptive: true`. `advancesCanonicalWorkflow: false`. NMI does not create or advance CC:10/11 state.
