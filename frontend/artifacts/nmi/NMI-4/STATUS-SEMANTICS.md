# NPA-T NMI:4 — Status semantics

| Status | Meaning |
| --- | --- |
| PRESENT | Canonical elements exist for the stage |
| PARTIAL | Some but not all expected pieces (e.g. variables without confirmed cause) |
| MISSING | Expected given earlier journey content but absent (e.g. Goal without KPI) |
| UNRESOLVED | Elements exist but evidence/epistemic status is unresolved |
| NOT_REACHED | Later than the current descriptive position (e.g. Decision without Execution) |
| NOT_APPLICABLE | Structurally not in play (e.g. Comparison with fewer than two Scenarios) |

Absence is not failure. MISSING ≠ NOT_REACHED ≠ NOT_APPLICABLE.
