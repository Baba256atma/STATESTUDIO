# NPA-T NMI:8 — Authority Audit

NMI:8 introduces no writer for:

Business/Project, Object, Goal, KPI, Data Reality, Evidence, Problem, Risk, Variable, Scenario, Decision, Execution, Outcome, Learning, Stage semantic state, Advisor memory, Queue.

Flags on `NMI_LIVE_HOST_CONTRACT` are all `writes* : false`. Canonical writes remain with existing authorities.
