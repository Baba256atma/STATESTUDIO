# NPA-T NMI:3 — Cross-domain relationships

Interpreted pairs remain owned by their canonical authorities:

- Goal ↔ KPI (`measures`)
- KPI ↔ Data (`evidenced_by`)
- Operation ↔ Problem (`belongs_to` / `supports` / `depends_on`)
- Problem ↔ Risk (`supports` or other declared NMI:1 kind)
- Problem ↔ Variable (`affects`)
- Problem ↔ Scenario (`addresses`)
- Scenario ↔ Decision (`selected_as`)
- Decision ↔ Execution (`executed_by`)
- Execution ↔ Outcome (`observed_by`)
- Learning ↔ prior context (`reassesses`)

NMI:3 shows they belong to one management system. It does not merge domain ownership.
