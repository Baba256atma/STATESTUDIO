# NPA-T RMS:4 — Manager Agent authority

RMS:4 owns simulated Manager behavior, profile, objective, perception memory, intent selection, turn generation, and conversation observation records.

Manager Agent is tagged `MANAGER_AGENT` with `managerChannelSource: MANAGER_AGENT`.

It does not own Stage, Advisor, NCA, ECA, NPS, Objects, confirmation, Decision, or Execution.
