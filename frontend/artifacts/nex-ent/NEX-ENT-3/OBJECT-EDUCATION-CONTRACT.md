## Educational vs business

Actors are presentation-only Stage catalog members. They must not populate `goalDiscovery`, `issueDiscovery`, `scenarioDiscovery`, `decisionExperience`, `executionPlanning`, `outcomeMonitoring`, `learningReassessment`, or Data Reality.

Example theme (not manager truth): Improve delivery / On-time delivery / Delivery delays / Further delays / Add temporary capacity / Use temporary capacity / Capacity action / Delivery improved. No invented percentages.

## Density

Each step shows only the current teaching set (typically one or two Objects). Recap shows six main types, without relationship lines that would claim causation.
