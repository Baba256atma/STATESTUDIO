# NPA-T STAGE-PROD:3 — Architecture inspection

## Production composition path

`/executive` → `ExecutiveShell` → `ExecutiveCockpit` → `NexoraExecutiveShell` → existing manager context and canonical referent → `projectNexoraDecisionTheatreFoundation` (DIR:1 / DTH scene intent and scene script) → existing NEX-MVP:4 Stage interaction projection → `projectStageProdLiveFoundation` → `NexoraStageMount` → `projectStageProdDirectorComposition` → `NEX-MVP:3/Nexora3DExecutiveStage` → `NexoraStageScene` → existing `NexoraStageObject` → visible production scene.

## First divergent layer

DTH already produced a canonical `sceneScript` containing scene intent, anchor, actors, semantic roles, relationships, and transition policy. `NexoraExecutiveShell` previously reduced that result to audit strings while `Nexora3DExecutiveStage` recomposed a fixed topology without consuming the script. The missing seam was therefore between the existing Theatre projection and the authoritative Stage host, not in Director, referent resolution, Object truth, or rendering.

## Canonical composition contract

`NPA-T STAGE-PROD:3/DirectorStageComposition` is a pure, read-only adapter over the complete existing `NexoraDecisionTheatreFoundation` and existing `NexoraMVPStageInteractionPresentation`. Theatre owns scene meaning. The adapter maps only approved actors, roles, relationships, candidates, attention, and transition policy into deterministic Stage placement and emphasis. The returned `presentation` remains the single input consumed by the existing Stage scene and Object renderer.

No store, runtime, semantic engine, referent resolver, presenter, or business truth was added. Canonical IDs remain render/select keys; labels remain display metadata.

## Proven scene structures

- Investigation: the focused Problem is centered; Theatre-approved related/supporting actors are grouped beneath it.
- Comparison: the exact existing Scenario participants are rendered as a balanced side-by-side pair.
- Commitment review: the existing candidate is centered with relevant comparison context; no Decision is created.

The structural signature includes family, canonical object IDs, positions, roles, and relationship IDs. Investigation and comparison differ in object membership and placement, not merely in a title.

## Missing-state and extension result

A missing Theatre composition preserves the existing Stage presentation by identity and invents no facts. Preserved/no-transition intent likewise leaves the presentation intact. Future scene families can supply certified Theatre actors and relationships through the same adapter without a parallel Stage authority; no Saved Scene, War Room, preference, chart, card, 3D, or persistence system was introduced.
