# NPA-T ORG:2 — Context and Identity Flow

## Existing seams reused

Left selection → NMI/Queue canonical ID → existing Stage selection/handoff → DIR:1/DTH composition → STAGE-PROD rendering → Right Context observes Stage focus and existing Advisor referent.

Stage actor selection → existing NEX-MVP interaction → canonical focus ID → existing Advisor bridge/referent path → Right Context projection.

Advisor command → `executeNexoraConversationalExperience` → existing conversational/runtime state → existing Stage presentation. ORG:2 does not intercept or reinterpret the command.

Open Detail → identity-only `{ canonicalId, kind, owner }` reference → reserved Detail Workspace boundary → existing RDI/Data Reality/CSV/Object authority. No Object/source record is copied into a region store.

## Production composition

- Left boundary wraps the existing `ExecutiveLeftNav` and `ExecutiveExplorerDrawer` without changing placement.
- Center boundary wraps the existing Stage column, `NexoraStageMount`, runtime bridge, workspace dial, and timeline.
- Right boundary wraps the existing `NexoraAdvisorInsightRegion` and exposes the existing Stage target/referent IDs as diagnostic handoff metadata.
- Detail boundary is hidden and reservation-only. ORG:6 owns visible Detail Workspace behavior.

## Identity guarantee

Region seams accept IDs only. They do not accept labels, Object state, evidence records, priority values, Decision records, Execution records, or Data Reality snapshots. Canonical owners remain the only sources of those values.
