# DATA-UX:4 Data Object Visual Grammar

Date: 2026-08-31

## Family

`DATA_OBJECT` is the third Nexora visual family. CSV is a subtype, not the family.

```
DATA_OBJECT
   └── CSV   (current)
   └── DATABASE / API / DOCUMENT   (not implemented)
```

## Form

The Stage participant is a compact hexagonal source token rendered in the existing R3F scene.

- Engineered hexagonal prism with restrained depth
- Inner lattice for CSV subtype identity
- Small diamond family mark (source artifact, not a file icon)
- Status is textual on the label; unresolved may add a small attention marker only when canonical `unresolvedFieldCount > 0`

It is not a floating HTML card, spreadsheet glyph, OS file icon, or executive KPI/Problem/Evidence body.

## Color

Color follows existing Stage materials. It does not encode trust, quality, importance, risk, freshness, or causality. CSV is not distinguished from future source types by hue.

## Size

Scale is fixed (`0.88`). Row count is not executive importance and does not change size.

## Motion

No continuous pulse, glow, or particle stream. Selection uses the existing restrained ring. Placement is Director-owned, not self-animated.

## Label

Default Stage copy:

- Source name
- `Data source · CSV · Ready | Needs clarification`

Schema, mappings, provenance, and preview stay in progressive disclosure.

## Accessibility

Critical meaning is also textual: name, source type, and status. Advisor can explain the same facts. Keyboard paths reuse existing Stage/inspection controls; Remove from Stage is a labeled button.
