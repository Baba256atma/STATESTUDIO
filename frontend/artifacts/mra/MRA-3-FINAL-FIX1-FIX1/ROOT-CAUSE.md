# Root cause

Reference resolution and Stage focus were already Capacity Gap. Final composition was not.

Pronoun meaning for `explain it` selected a **historical Scenario collection member** (Capacity Expansion Plan, `CONTEXT_RECENT_SUBJECT`) after Stage click + named return to Capacity Gap. `applyContextualMeaningToIntent` promoted that pick into a **primary target hint**, so CC:2 treated a related Scenario as an explicit manager name. Scenario explanation fidelity then composed Capacity Expansion Plan.

That is subject substitution, not legitimate Scenario assessment:

- Legitimate: named Demand Surge, how-sure after a Scenario, collection comparison, ordinal “second one”
- Stale: deictic explain of a newer Problem while a leftover Scenario collection/assessment remains in session

A prior global “skip Scenario remap when current referent is not a Scenario” was correctly reverted: it broke NXA how-sure / Demand Surge follow-ups while Stage/current subject was still an Object.

This repair does not globally suppress Scenario assessment and does not make Stage always win.
