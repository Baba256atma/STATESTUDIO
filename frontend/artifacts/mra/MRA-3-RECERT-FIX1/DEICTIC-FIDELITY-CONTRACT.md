# Deictic fidelity contract

Reuse `subjectCompositionFidelity.ts` (MRA:3-FINAL-FIX1-FIX1). No second provenance system.

A deictic follow-up preserves the newest valid conversational subject unless the manager explicitly names another object or the utterance semantically requests a related object.

Words such as it / that / this / this one / that one do not mint a new explicit subject.

Follow-up families (operation may change; subject must not):

- explain it / tell me about it / tell me more
- investigate it / look deeper
- what else do we know about it

Assessment families remain Scenario reasoning about the **same** resolved Scenario:

- how sure / why / what impact

Collection members and Stage focus are context. They do not replace the current referent for a pronoun follow-up.
