# Collection exit rules

- Naming, clicking, ordinally selecting, or explicitly returning to one valid object establishes single-subject primary mode.
- The prior collection remains stored for navigation and supporting context.
- Targeted deictic follow-ups use the established subject, not a collection member or first-ranked item.
- A new collection request or ordinal selection may validly re-enter collection mode.

Focused cases A, B, C, F, K, and L pass.
