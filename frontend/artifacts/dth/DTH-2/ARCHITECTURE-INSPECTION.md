# DTH:2 Architecture inspection

Executive Object vs Iconic Object language on the certified DTH:1 foundation. No second Stage, Object registry, Director, Advisor, Runtime, or domain store.

## Prerequisite

DTH:1 = CERTIFIED (`frontend/artifacts/dth/DTH-1/DTH-1-CERTIFICATION-REPORT.md`). Baseline DTH:1 + DIR:1 tests passed before implementation.

## Path (unchanged)

Manager interaction or conversation → canonical intent/context → Runtime → DIR:1 → `projectNexoraDecisionTheatreFoundation` (now including DTH:2 visual-family + optional Iconic projection) → existing Stage renderer → Advisor (read-only Theatre context).

## Inspected authorities (reused, not replaced)

| Concern | Authority | DTH:2 action |
|---|---|---|
| Stage subjects / scene | NEX-MVP:3/4 | Unchanged writers |
| Executive Object catalog IDs | NEX-MVP:4 catalog + context fixtures | Referenced only |
| Focus / selection / trail | NEX-MVP:4 | Iconics never written |
| Queue / collections | STAGE-PROD Queue | Iconic IDs excluded |
| One-hop topology | existing disclosure + connections | Unchanged |
| Director | DIR:1 | May select registered Iconics from explicit sources only |
| Advisor | existing composer | Consumes Advisor-readable Iconic context; no new routes |
| Evidence / confidence / uncertainty | existing NXA:5 / MO / Data Reality | Projected only when an authoritative source is supplied |
| Scenario / Decision / Execution | CC:9–11, NEX-EXP | Remain Executive Objects |
| HUD / object panel / object click | existing Stage controls | `data-visual-family="executive-object"`; click path unchanged |
| Accessibility / keyboard | existing Stage + Iconic `aria-label` | Iconic click is identity-only and does not focus the owner |

## Safe to extend

- DTH:1 foundation projection and Advisor-readable context
- Supported-capability list (`executive-versus-iconic-object-language`)
- Optional Stage presentation of already-projected Iconics

## Must remain unchanged

- Canonical Object registry and IDs
- Queue membership and counts
- Navigation trail / breadcrumbs
- Relationship topology
- Decision / Execution / Outcome / Learning / evidence writes
- DTH:3 visual grammar (color, size, motion, distance, line weight)

## Iconic source policy

Live `/executive` does not currently expose honest Cost/Time numeric sources. The projector therefore emits **zero** Iconic Objects unless `iconicAuthoritativeSources` is supplied (deterministic fixtures/tests). Live certification is safe-empty, not fabricated.
