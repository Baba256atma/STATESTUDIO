# DTH:3 Architecture inspection

## Pipeline (unchanged ownership)

Authoritative runtime state → DTH Theatre projection (DTH:1) → Executive/Iconic language (DTH:2) → NexoGraph semantic directives (DTH:3) → renderer token resolution → visible Stage → Advisor-readable explanation.

Director may select supported directives. Renderer may resolve tokens to CSS/WebGL. Neither creates business meaning. Raw CSS is not semantic authority.

## Reused authorities

- DTH:1 Theatre foundation, Stage compatibility adapter, Advisor-readable context, diagnostics, invariants, Director boundary
- DTH:2 visual family, Iconic registry, Iconic projection, stable Iconic IDs
- Existing object `status` / `attention` / focus / selection / Stage layout
- DIR:1 presentation director
- NEX-MVP Stage and object interaction

## Not created

- Second status store
- Parallel Stage, Queue, catalog, topology, or evidence store
- War Room atmosphere (DTH:4)
- Scene Intent / Scene Script / Visual Behavior Engine
- Card, Chart, NexoSelect, NexoTime, NexoCause, NexoRisk views

## Live policy

Live `/executive` applies identity form tokens, status→palette mapping, attention halo tokens, and equal size. Relationships without explicit support stay `line-unknown` with neutral weight and no causal language. Iconic count remains zero unless authoritative Iconic sources exist. Missing data does not become zero, false, or low risk.
