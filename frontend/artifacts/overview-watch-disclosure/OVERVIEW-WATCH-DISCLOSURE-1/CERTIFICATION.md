## Watch vs attention vs state

- **State** (`status`): condition of the object (`stable` / `watch` / `risk` / `unresolved`).
- **Attention** (`attention`): whether the manager should currently care (`normal` / `elevated` / `important` / `critical`).
- **Watch spatial role**: Overview disclosure category for eligible attention bodies that fit the budget.
- **Watch status token**: one eligibility/rank input, not a separate store.
- **OVS material**: consumes state; does not select Overview membership.
