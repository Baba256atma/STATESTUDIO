# EXI:5 — Learning Presentation

Reuse CORE-OUT:2. Do not interpret Learning independently.

## Status

Candidates are shown with their Core status: candidate / supported / inconclusive / contradicted / conflicting.

## Scope

Case-specific Learning is labeled as case-specific.

Generalized Learning is shown only when CORE-OUT:2 `scope === "generalized"` and `repeatability === "repeated-consistent"`.

One successful Outcome must not appear as a general rule.

## Empty states

- No candidates: “No promoted Learning is available yet. Nexora will not invent one.”
- Actual exists, no eligible Learning: “An outcome was observed, but there is not enough evidence to promote a learning yet.”
- Conflicting: “Evidence is conflicting. No reliable learning has been promoted.”
- Missing provenance: “Learning is not authoritative while provenance is incomplete.”

## Live `/executive`

0 CORE-OUT:2 candidates. Honest empty Learning is required and is what EXI:5 shows.

## Confidence

Mapped from CORE-OUT:2 `evidenceStrength`: strong / moderate / weak / unknown.

Stale → unknown. Partial → weak. No presentation-only score.
