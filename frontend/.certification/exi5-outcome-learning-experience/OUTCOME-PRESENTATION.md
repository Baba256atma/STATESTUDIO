# EXI:5 — Outcome Presentation

Reuse CORE-OUT:1. Do not re-evaluate.

## Expected

CORE-OUT:1 `expectedOutcome.statement`, or “No recorded expectation is available yet.”

Remains a PREDICTION / recorded expectation. Commitment does not make it FACT.

## Observed

- Linked Actual → CORE-OUT:1 actual statement
- No Actual → “No validated actual outcome is available yet.”
- Current KPI without Outcome linkage → “Current measurements are Reality, not a Decision Outcome.”
- Execution subject without Actual → “Execution is recorded as complete. The business outcome is still unknown.”

Execution completion is never presented as Outcome achieved.

## Comparison

`presentOutcomeAssessment(CORE-OUT:1)`:

- pending Actual
- comparable met / partially-met / not-met / exceeded
- stale / conflicting / incomplete

No SUCCESS/FAILURE badge. No invented ROI.

## “Did it work?”

If comparable and met/exceeded/partially-met:

> The expected Outcome was met. Causal attribution has not been established.

unless CORE-INT:3-backed causal Learning is promotion-eligible.
