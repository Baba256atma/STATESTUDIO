# Initiative greeting policy

A bare greeting (`hi`, `hello`, `hey`, good morning/afternoon/evening) is a SOCIAL / ENTRANCE turn.

Default copy: `Hi. I’m ready.` (existing NEX-EXP greeting). Do not append ordinary NCA:5 / attention review offers.

NCA:5 may interrupt a greeting only when the signal is genuinely CRITICAL and interruption policy allows it.

Non-critical issues may surface later when the manager asks what matters, the conversation enters relevant context, there is no active request, a proactive no-user-turn evaluation runs, or urgency rises.

This is stronger than generic manager-turn protection. It does not disable NCA:5.
