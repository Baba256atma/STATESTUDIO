# Attention language invariants

Do not explain attention with synonyms of attention.

Forbidden tautologies:

- needs attention because it is worth monitoring
- needs monitoring because it needs attention

Prefer concrete reasons: below target, material deterioration, unresolved issue, risk escalation, missing outcome, goal blocker.
