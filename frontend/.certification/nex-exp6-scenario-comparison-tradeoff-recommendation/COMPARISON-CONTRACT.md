# Scenario Comparison Contract

SCENARIO ≠ COMPARISON ≠ TRADE-OFF ≠ RECOMMENDATION ≠ DECISION ≠ EXECUTION

NEX-EXP:6 projects comparison from existing Scenario facts through EI:4 helpers.

- Dimensions come from Goal, horizon, constraints, risks, unknowns, baseline — not a universal scorecard.
- `numericalScore` is always `null`.
- Numeric values appear only from recorded evidence.
- Unknown cost is not ranked as cheaper.
- Constrained/invalid Scenarios are not equal ranked alternatives.
- Expected effects remain PREDICTED, not observed.
- Comparison does not mutate Data Reality.
