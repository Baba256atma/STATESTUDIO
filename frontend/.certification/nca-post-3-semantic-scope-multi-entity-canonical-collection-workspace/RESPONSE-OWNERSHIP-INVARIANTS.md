# Response-ownership invariants

Primary owner examples:

| Request | Owner |
| --- | --- |
| Explain Risk and Delivery relation | RELATIONSHIP_EXPLANATION |
| If Delivery is late, is it okay? | CONDITIONAL_EVALUATION |
| Capacity Gap and Margin Pressure are Problems | MULTI_ENTITY_ASSERTION |
| Show all Problems | COLLECTION_QUERY |
| Why did Capacity Gap disappear? | COLLECTION_CHANGE_EXPLANATION |
| Can you add object? | PRODUCT_CAPABILITY |
| Explain Stage | PRODUCT_KNOWLEDGE |
| What is on Stage? | WORKSPACE_STATE |
| How do I use Nexora? | HELP_TEACH (existing teach copy) |

NCA:4 may advise only when owner is BUSINESS. NCA:3 asks only when scope is BUSINESS and the gap is material to that request. NCA:5 may interrupt only when already justified. Stale Risk uncertainty must not appear on an unrelated Capacity Gap change question.

Every manager-facing clause must support the current primary purpose or an explicitly justified critical interruption.
