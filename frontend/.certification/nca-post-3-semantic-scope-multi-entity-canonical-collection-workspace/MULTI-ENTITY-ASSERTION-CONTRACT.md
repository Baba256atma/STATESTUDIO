# Multi-entity assertion contract

Applies when two or more catalog references are asserted (classification, qualitative state, “these two”).

Not FOCUS / LOCATE. Not an unsolicited NCA:4 recommendation.

Classification (“are Problems”) is manager-provided. Canonical Problems membership is not silently rewritten. If canonical membership disagrees, Nexora states the distinction.

Requires at least two resolved references or an explicit “these two” — a lone “and” in an answer such as “seasonal and should normalize” is not an assertion.
