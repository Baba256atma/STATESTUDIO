# Beta User Guide

## Who this is for

Executive pilots completing the decision journey without developer assistance.

## Where to start

1. **Settings** → Load Manufacturing Demo  
2. Follow **Official Beta Scenarios** (Scenario 1–10) in Settings  
3. Use **Recovery Center** if a connector or simulation fails — never a dead end  

## Support surfaces

| Surface | Purpose |
|---------|---------|
| Settings | Flags, demos, validation, audit |
| Data | Enterprise Connectors |
| Knowledge | Metadata meaning |
| Intelligence | Signals & recommendation context |
| Simulations | Future State exploration |
| Journal | Audit packs |

## Known posture

CSV connectors are production-quality for beta intake.  
Other connectors are shells.  
Simulation is deterministic rule-based — not predictive AI.
