# Executive Quick Start

Welcome to the Nexora Executive Cockpit Beta.

## Complete journey (no developer help)

1. Open **Data** → Connect CSV (`inventory.csv`) → Approve → Publish  
2. Open **Knowledge** → confirm Inventory / MAT_QTY meaning  
3. Set Mode to **Scenario** → select an alternative  
4. Open **Simulations** → Inventory Shortage → Increase Safety Stock → Run  
5. Create **Decision Candidate** (Draft) → Approve as Manager  
6. Mode **Execution** → Start Execution  
7. Mode **Monitoring** → Create Snapshot  
8. Open **Journal** → review Connector · Simulation · Decision · Execution · Monitoring packs  

## Terms (do not mix)

| Term | Meaning |
|------|---------|
| Mode | Executive workspace (Goal → War Room) |
| Pack | Timeline case file identity |
| Model | Active executive model (e.g. Supply Chain) |
| Object | Stage entity (Inventory, Factory, …) |
| Scenario | Alternative path in Scenario Mode |
| Simulation | Isolated Future State from assumptions |
| Workspace | Synonym for active Mode context |

## Settings

Open **Settings** for Demo Mode, Feature Flags, Beta Validator, Recovery Center, and Audit Console.
