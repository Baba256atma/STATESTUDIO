# Metadata Guide

Metadata gives Runtime IDs executive meaning.

## Examples

| Technical | Display |
|-----------|---------|
| `MAT_QTY` | Available Inventory |
| `inventory` | Inventory |

## Rules

- No automatic Metadata creation on connector discover  
- Manager confirms mappings  
- Every demo Runtime Object must have Metadata (no orphans)  
- Knowledge Explorer: Objects, Fields, Domains, KPIs, Glossary
